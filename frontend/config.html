安全须知：密钥只写入本机 backend/data/.secrets/*.json（已被 .gitignore 排除）， 本页面与所有接口永不回显明文，只显示掩码；配置接口只接受 127.0.0.1 本机请求， 且只提供 POST 端点。不要把密钥贴进聊天、截图或提交记录；一旦泄露请立即到服务商后台轮换。 服务默认只监听 127.0.0.1，请勿把 HOST 改成 0.0.0.0 直接暴露公网。
配置页是静态文件，走已有 /static 挂载；配置接口为 POST /api/config/state · POST /api/config/save · POST /api/config/test，另有一个只读的 GET /api/ui/theme 给主页面同步风格， 仅新增 POST 端点，GET 路由集合不变。
设 CONFIG_API_ENABLED=0 可整体关闭配置能力；密钥文件也可用 python -m tools.set_llm_key 命令行维护。
主界面右上角齿轮入口可在密钥配置、调度任务管理、运行监控之间切换； 从静态预览打开时 ?api= 会自动透传，不会回退到任何固定端口。
